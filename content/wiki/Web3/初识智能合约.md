### 合约的根本性质
 - 商业、“法律”的契约关系

 - 根本性质：智能合约表达人与人、组织与组织的间经济活法律关系。

    - 智能合约的**不可篡改性**（immutabilty）是关键属性之一
    - 合约的升级应视为对原契约的一次修改，需经过定约方共识

### 合约的运行机制

- Transation驱动的EVM 虚拟机 
  - 该虚拟机是由以太坊、等。
  - 该虚拟机是逻辑虚拟机并实际开发理解的虚拟机
- 没有所谓的并发问题！
  - 交易序列驱动EVM执行，确保逻辑顺序化处理、
  - EVM执行机制避免了并发问题，因为交易是按顺序执行的
- Transaction的原子性与闪贷
  - 交易具有原子性，要么全部成功，要么全部失败并回滚状态

```
// SPDX-License-Identifier: GPL-3.0

pragma solidity >=0.8.2 <0.9.0;

/**
 * @title Storage
 * @dev Store & retrieve value in a variable
 * @custom:dev-run-script ./scripts/deploy_with_ethers.ts
 */
contract Storage {

    uint256 number;

    /**
     * @dev Store value in variable
     * @param num value to store
     */
    function store(uint256 num) public {
        number = num;
    }

    /**
     * @dev Return value 
     * @return value of 'number'
     */
    function retrieve() public view returns (uint256){
        return number;
    }
}
```

- // SPDX-License-Identifier: GPL-3.0
  - license 授权方式 
  - “合约”必然是开源的，因此需要授权方式
- pragma solidity >=0.8.2 <0.9.0;
  - 编译器版本申明
  - solidity 编译版本 >=0.8.2
  - 语义版本：<0.9.0
- constract 
  - 类似 java 的 class等
  - go 的 struct
- uint256
  - 256位的整型数
- 成员函数
  - function store(uint256 num) public {....}
    - public 可见性
    - number 是成员变量 （无需this 等）
  - function retrieve() public view returns (uint256) {}
    - view : 视图 表名该函数是一个**读操作**，**不是写操作**
    - returns: **注意是s ** 返回值是可以有多个
